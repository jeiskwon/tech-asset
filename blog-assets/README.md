# Blogger image archive

Public illustrative images for seasonlivingnote, phonehelpguide, digitaleasylab and smarthomemanual.

Folders: season/, phone/, digital/, home/. Each post gets one topic-specific representative image. Use descriptive date-based filenames; never overwrite a published asset. Prefer JPEG or WebP around 1600px wide, with alt text. No secrets or personal photographs.

Generated mood images are illustrations, not proof of physical testing or exact device interfaces. For phone/PC tutorials, use verified screenshots when exact menus are essential; do not invent interfaces.

Workflow: generate and inspect image, upload binary via GitHub Git Data API, retain other repository files, confirm public URL, then include image URL in Blogger email HTML. If image upload or public URL validation fails, withhold publishing email and provide draft. Never use sandbox, temporary authenticated URLs or data URLs in published HTML.

Do not change site app code from this workflow.
